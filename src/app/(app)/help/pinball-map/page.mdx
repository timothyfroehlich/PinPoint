## How the integration works

PinPoint tracks one Pinball Map location, the venue. It reads that location's
lineup every hour and stores what it saw; every PinPoint page renders from that
stored copy, so opening a page never contacts Pinball Map.

PinPoint never writes to Pinball Map on its own. Every change to the public
lineup is a person pressing a button and confirming it, and Pinball Map records
the change under that person's own Pinball Map account.

Four facts about each machine are kept separately, and none of them changes
another automatically:

- **Model** — which Pinball Map catalog title the machine is.
- **Lineup setting** — whether PinPoint says the machine belongs on the lineup.
- **Lineup** — what Pinball Map currently shows for the venue.
- **Availability** — whether the machine is at the venue and available for
  play: On the Floor, Off the Floor, On Loan, Pending Arrival, or Removed.

When the lineup setting and the lineup disagree, the machine is **Out of sync** until
someone pushes the change to Pinball Map or changes the lineup setting.

### Link your Pinball Map account

Pushing changes to Pinball Map runs as your own Pinball Map account. Link it
once from [Settings](/settings#pinball-map) → **Connected Accounts** →
**Link Pinball Map**, signing in with your Pinball Map username or email and
password. PinPoint keeps the account's API token and never stores your
password.

<HelpScreenshot src="/help/pinball-map/account-linked.png" alt="The Pinball Map row in Connected accounts, reading Linked as a username, with an Unlink button" width={792} height={93} />

- **Without a linked account** you can still change the lineup setting. Instead of a push
  button, the status row tells you what to change and links to the venue's
  Pinball Map page. The machine stays Out of sync, and any member with a linked
  account can push it.
- **Authentication failed** means Pinball Map rejected your saved token. Use
  **Reconnect** in Settings to sign in again.
- **Unlink** deletes PinPoint's copy of the token. Pinball Map offers no way to
  revoke the token itself.

### Refreshing and Pinball Map's API

PinPoint reads the lineup automatically once an hour. **Refresh** reads it now.

Pinball Map is a community-run service, and PinPoint keeps its traffic to their
API low on purpose. Pages show PinPoint's stored copy of the lineup and never
call Pinball Map when they open. Refreshes are capped for everyone combined,
across the Manage tab, the lineup page, and the admin page: three can run back
to back, then one becomes available every three minutes, up to 20 an hour. A
failed refresh still counts. While none is available, the button shows a
countdown. Press Refresh only when you need something newer than the last
hourly read, such as checking a change you just made on pinballmap.com.

## Machines

### Match a machine to a Pinball Map title

A machine's Pinball Map title is set under **Model Details** on its **Manage**
tab. With **Source** set to **Pinball Map**, choose the **Model**, then the
**Edition** when the title comes in several (Pro, Premium, LE). Save with the
form's **Save** button.

<HelpScreenshot src="/help/pinball-map/model-details.png" alt="Model Details with Source set to Pinball Map, Model set to Attack from Mars, Bally, 1995, and Edition reading Only one edition" width={920} height={180} />

- A matched machine's manufacturer and year come from Pinball Map's catalog and
  cannot be edited.
- Every machine needs one or the other: a Pinball Map title or **Manual Entry**.
- Use **Manual Entry** for a game Pinball Map's catalog does not carry: a
  homebrew, a flipperless game, or a title too old or obscure for the catalog.
  You enter its model details by hand, and it has no lineup controls.
- Changing the match resets the lineup setting to **Off the lineup** (a
  **Don't sync** setting is kept). It does not remove the old title's entry
  from Pinball Map. If no other machine uses the old title, the leftover entry
  appears on this machine's Manage tab with its own **Remove** action.
- While the form has unsaved changes, the Pinball Map controls below it wait
  until you save or discard.

### The Pinball Map box on the Manage tab

Each matched machine's **Manage** tab has a Pinball Map box under
**Integrations**. The header links to the venue's Pinball Map page and shows
when the lineup was last refreshed, with **Refresh** and **Help**. An
**Out of sync** badge appears when the lineup setting and the lineup disagree.

<HelpScreenshot src="/help/pinball-map/listing-control-in-sync.png" alt="The Pinball Map box for Attack from Mars: Lineup set to On the lineup, Status reading On the location's lineup" width={886} height={156} caption="In sync: the lineup setting is On the lineup and Pinball Map lists the game." />

#### Lineup setting

- **On the lineup** — the machine belongs on the venue's public lineup.
- **Off the lineup** — it does not.
- **Don't sync** — PinPoint leaves this machine alone. Its status is still
  shown, but it is never flagged Out of sync, never appears on the lineup
  page's review lists, and does not receive Pinball Map comments.

Changing the lineup setting writes only to PinPoint. It takes effect immediately, needs no
confirmation, and can be changed back at any time.

#### Insider Connected

Titles that Pinball Map marks as Insider Connected eligible get a second
toggle: **On**, **Off**, or **Don't sync**. With **Don't sync**, PinPoint shows
Pinball Map's current value beside the toggle and never flags a difference.
With **On** or **Off**, a difference from Pinball Map makes the machine Out of
sync and offers **Update Pinball Map**. Titles that are not eligible show no
Insider Connected toggle.

#### Push the change to Pinball Map

When a machine is Out of sync, the status row offers the one action that makes
Pinball Map match: **Add to Pinball Map**, **Remove from Pinball Map**, or
**Update Pinball Map** when only Insider Connected differs. Adding also applies
the Insider Connected setting. Each action asks for confirmation and names the
public change.

Without a linked Pinball Map account, the status row shows no push button. It

#### Removing an entry

Pinball Map hides a removed entry rather than deleting it. Re-adding the same
game at the venue within **7 days** restores the entry with all its comments.
After 7 days the entry and its comment history cannot be restored. The remove
confirmation shows how many comments the entry has. If PinPoint's copy of the
lineup is more than 5 minutes old, it refreshes before you can confirm, so the
count is current.

### Several cabinets of the same title

Pinball Map lists a title at most once per location, so cabinets sharing a
title share one entry. The title is listed when at least one of its cabinets is
**On the lineup**; it is Lingering only when every cabinet is **Off the
lineup**. Each cabinet that is On shows the entry as **Shared** and names the
others. A cabinet that is Off while a sibling keeps the title listed shows
**Covered**.

<HelpScreenshot src="/help/pinball-map/listing-control-shared.png" alt="The Pinball Map box for Godzilla GDZ: lineup setting On the lineup, Insider Connected set to Don't sync with Pinball Map: On, status Shared with GDZ2" width={886} height={156} caption="Shared: GDZ and GDZ2 are both On the lineup and share Godzilla's entry." />

For Insider Connected, the shared entry is set On when any cabinet wants On,
otherwise Off when any wants Off.

### Adding a new machine

On the **New Machine** page, choosing a Pinball Map model shows the Pinball Map
choices for the new machine:

<HelpScreenshot src="/help/pinball-map/new-machine.png" alt="The New Machine page's Pinball Map block with the lineup setting toggle set to On the lineup" width={886} height={86} />

- **Lineup setting** starts at **Off the lineup**, or **On the lineup** when you came
  from **Create in PinPoint** on the lineup page.
- **Insider Connected** appears for eligible titles. When the title is already
  on the lineup, it starts at Pinball Map's current value.
- **Add to Pinball Map after creating** appears when the lineup setting is On the lineup,
  the title is not already listed, and you can push. It is ticked by default.
  If the add fails, the machine is still created, and its Manage tab shows the
  failure and the Out of sync state.

### Comments from Pinball Map

Comments on a listed entry are copied into the **Timeline** of every cabinet
of that title that is **On the lineup**. A shared entry's comments appear on
each covering cabinet, marked with the other cabinets that have them.
Watchers of those machines are notified when a new comment arrives. Machines
set to Don't sync receive no comments.

<HelpScreenshot src="/help/pinball-map/timeline-comment.png" alt="A Pinball Map comment on the Godzilla timeline, marked Shared entry, also on GDZ2, with a Convert to issue button" width={784} height={147} />

- **Convert to issue** creates a PinPoint issue from the comment. PinPoint
  never does this on its own. Each comment becomes at most one issue; after
  conversion, every copy links to it. If the issue landed on the wrong
  cabinet, move it to another machine.
- **via Pinball Map** opens the venue's Pinball Map page.
- PinPoint does not post comments to Pinball Map. Post them on Pinball Map
  directly.

## The lineup page

The lineup page compares, title by title, what PinPoint says the lineup should
be with what Pinball Map shows, and lists every difference by the action that
fixes it. Open it from the **Pinball Map** button on the Machines list or from
**Pinball Map lineup** in the admin menu. The page is laid out for a desktop
screen.

<HelpScreenshot src="/help/pinball-map/lineup-page.png" alt="The Pinball Map lineup page: header with location, entry count, Refresh, and Confirm lineup on Pinball Map; review counts; and the Out of sync, In PinPoint, not linked, and On Pinball Map, not linked sections" width={1280} height={780} />

The header shows the venue, the number of entries, when PinPoint last
refreshed, the date Pinball Map last recorded an update to the location, and
**Confirm lineup on Pinball Map**. Below it, a summary counts the rows to
review in each section. Machines marked Removed are left out of the
comparison except where they still affect the lineup.

### Sections

- **Out of sync** — titles where PinPoint and Pinball Map disagree, each tagged
  with its fix: **To add**, **To remove**, or **To update** (Insider
  Connected). Each row has the matching push button.
- **In PinPoint, not linked to Pinball Map** — machines with no Pinball Map
  title that are not Manual Entry and not set to Don't sync. **Edit Machine**
  opens the machine to match it.
- **On Pinball Map, not linked to a PinPoint machine** — entries on the lineup
  that no PinPoint machine is matched to. Each row offers:
  - **Link to PinPoint** — match the entry to an existing machine. That
    machine is set On the lineup.
  - **Create in PinPoint** — open the New Machine page with the title chosen
    and the lineup setting On the lineup.
  - **Remove from Pinball Map** — take the entry off the lineup.

  When a PinPoint machine is a different edition of the same game (Pro on
  Pinball Map, Premium in PinPoint), the row names it as a possible match.
  Nothing is linked until you choose.
- **Availability conflict** — machines On the lineup that are not on the
  floor, tagged **Alert** (Removed or Pending Arrival) or **Note** (On Loan or
  Off the Floor). **Edit Machine** opens the machine.

<HelpScreenshot src="/help/pinball-map/lineup-not-linked.png" alt="The On Pinball Map, not linked to a PinPoint machine section, with Remove from Pinball Map, Create in PinPoint, and Link to PinPoint buttons on each row" width={1224} height={354} />

<HelpScreenshot src="/help/pinball-map/lineup-link-dialog.png" alt="The Link to a PinPoint machine dialog, with a searchable list of machines and a Link button" width={512} height={514} caption="Link to PinPoint: choose the machine that is this entry." />

Titles that are in sync collapse to a count you can expand. A footer counts
what the page does not compare: Manual Entry machines, titles set to Don't
sync, and Removed machines. Every action on the page acts on one entry at a
time, with the same confirmations as the Manage tab.

### Confirm lineup on Pinball Map

**Confirm lineup on Pinball Map** tells Pinball Map that the venue's whole
lineup is accurate as of today. If PinPoint's copy is more than 5 minutes old,
it refreshes first. When entries are Out of sync or not linked to a PinPoint
machine, the dialog lists them, and you can confirm anyway or cancel.
Confirming changes no entries.

## For admins

### The tracked location

The tracked location is set under **Admin** → **Integrations** →
**Pinball Map**.

<HelpScreenshot src="/help/pinball-map/admin-integration.png" alt="The Pinball Map card on Admin Integrations: Location ID with Check ID, the resolved Austin Pinball Collective location, and Sync health with Sync now" width={792} height={464} />

- **Location ID** is the number in the location's Pinball Map URL. **Check ID**
  looks the location up and shows its name; **Save** is available only after a
  successful check.
- **Sync health** shows the last successful sync, the last attempt and its
  result, and how many machines the stored lineup holds. **Sync now** uses the
  same shared allowance as Refresh.
- **Clearing the location** stops all automatic and manual refreshes. Machine
  matches, lineup settings, and imported comments are kept, and setting the same
  location again resumes where it left off.
- **Changing to a different location** keeps every machine's match and lineup setting.
  Machines On the lineup whose titles are not at the new location show as
  Missing, and machines Off the lineup whose titles are already there show as
  Lingering, until someone pushes the changes.

### Region alerts

Region alerts post to a Discord channel when a machine is added to, or removed
from, any location in a Pinball Map region, such as Austin. They watch the
whole region, not just the venue, and are independent of the tracked location.
They are set in the same Pinball Map card on **Admin** → **Integrations** and
use the Discord bot set up under **Discord** on that page.

<HelpScreenshot src="/help/pinball-map/admin-region-alerts.png" alt="The Region alerts section: a Region dropdown set to Austin, an empty Alert channel field with Send test message, and the status Not configured" width={742} height={236} />

- **Region** — the Pinball Map region to watch, picked from Pinball Map's list
  of regions. One region at a time.
- **Alert channel** — the Discord channel id to post to. Alerts are on when a
  region and a channel are set and the Discord bot is working. Clear the channel
  to turn them off.
- **Saving** checks that the bot can see the channel and appears to have
  permission to post, and always saves what you entered, even when the check
  fails.
- **Send test message** posts a test line to the channel. A successful post is
  the only proof the bot can post there.

How the alerts behave:

- PinPoint checks the region once an hour. There is no way to run a check on
  demand; Send test message is the only manual post.
- Only machines added to or removed from a location are announced. Condition
  comments, high scores, new locations, and photos are not.
- Each alert names the machine and the location, links to the location's
  Pinball Map page, and credits Pinball Map.
- Each change is announced once. A post that fails is retried on the next
  hourly check.
- The first check after alerts are turned on, or after the region changes,
  records the region's current machines without posting, so the channel is not
  flooded with everything already there.
- A machine swapped for another edition, or a game swapped for another, posts
  the removal and the addition together.

## Troubleshooting

- **No Add or Remove button.** Link your Pinball Map account in Settings. The
  buttons also require being the machine's owner, a technician, or an admin.
- **Still Out of sync after changing the lineup setting.** The lineup setting records what PinPoint
  wants; the lineup changes only when someone pushes the change.
- **Refresh is disabled with a countdown.** The shared allowance is used up.
  Wait for the countdown; the hourly refresh still runs.
- **The status says Waiting.** PinPoint has not read the location yet. Press
  Refresh.
- **The box is greyed out.** The machine has no Pinball Map title, or no
  tracked location is set. The status line says which.
