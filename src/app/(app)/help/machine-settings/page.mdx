## Start here

Most people want one thing: the machine's normal setup. That's the set badged
**★ Owner's default**, always first in the list. Want the competition config
instead? Filter to **🏆 Tournament**.

Two boxes sit above the sets, both machine-wide:

- **Before you change anything** — the owner's request for how to treat this
  machine: who to ask, what to avoid.
- **How to change settings** — how to reach the adjustments: coin-door buttons
  (back / value− / value+ / enter), where the DIP switches are, the
  launch-button sequence on a P3.

## Sets and who can edit them

A **settings set** is one named configuration (_Tournament_, _Home_, _Factory
defaults_). Its badges tell you who may change it:

Anyone can view a published set. Creating a set at all takes **owner**,
**technician**, or **admin** — see [Roles & Permissions](/help/permissions).
Without edit rights on a set, its fields are read-only and its ⋮ menu doesn't
appear.

Two more badges are independent of the kind:

- **★ Owner's default** — the owner's canonical setup. One per machine, always
  an owner set, always public.
- **🏆 Tournament** — competition-ready. Any set can carry it, including the
  Owner's default.

## The ⋮ menu

- **Publish** / **Make private** — shows or hides the set. The Owner's default
  must stay public, so unset it as the default first.
- **Set as owner's default** — owner or admin, owner sets only. Replaces
  whichever set held the title.
- **Tournament** — tags or untags; needs edit rights on the set.
- **Duplicate** — copies as "_name_ (copy)", a private draft owned by you. It
  carries the Tournament tag but never the default status, and its kind is
  re-derived from whoever copied it — so your copy of someone else's owner set
  becomes a **Community** set you can actually edit.
- **Delete** — removes the set and everything in it. Can't be undone.

One quirk worth knowing: if you own the machine and it has no Owner's default
yet, your first set skips the draft stage — it's published and made the default
straight away. Every set after that starts as a private draft.

## Filtering the list

Pick one of **All / Mine / Owner's / Community**, then layer the independent
**Tournament** toggle on top. **All** clears everything. **Mine** appears once
you've made a set; **Owner's** is hidden if you _are_ the owner, since **Mine**
already covers it.

## Sections

A set's body is an ordered list of **sections** from **Add section**. Drag by
the grip to reorder; the ⋮ on a section deletes it.

- **Software settings** — the adjustments menu. **ID / Setting / Value** rows
  (`A.1 01` / `Balls Per Game` / `5`) plus a **baseline** picker (Factory,
  Competition, …). One per set.
- **DIP switch bank** — physical switches on EMs and early solid-state games:
  number, **ON/OFF**, description. Add one bank per physical bank.
- **Other table** — a free **ID / Setting / Value** table under your own
  heading, for Jones plugs, transformer taps, board jumpers. Repeats.
- **Post positions** / **Rubbers** — preset notes with fixed headings, for the
  two most common physical-setup notes. One each per set.
- **Other / Notes** — a free note under your own heading. Repeats.

Note sections take rich text — headings, lists, bold, links.

## Editing

Every field is live. Changes save on their own a moment after you stop typing
or move on; there's no Edit/Done step. Deletes and reorders save immediately.

- **Desktop** — click a value to change it. **Add row**, **Add section**, and
  the trash icon do what they say.
- **Mobile** — tap a row to edit it in a sheet.

If a save fails, a banner appears at the top and **Retry** re-sends it — your
edits stay put. Leaving the tab flushes anything unsaved in the background.

## Timeline

Creating, editing, and deleting a set record a **settings** entry on the
machine's Timeline. Publishing, tagging Tournament, and changing the Owner's
default don't. The **settings** filter is off by default — turn it on to see
configuration history.
