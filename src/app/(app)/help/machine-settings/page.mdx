## Which set do I want?

The one badged **★ Owner's default** — the setup the machine's owner considers
canonical. There's at most one per machine and it always sorts first.
**🏆 Tournament** marks competition-ready sets; a set can be both.

## Who can edit what

Two separate things decide that: a set's **kind** — Owner or Community, fixed
when it's created — and whether it's still a **private draft**. A draft is
creator-only whatever its kind.

Drafts are invisible to everyone else, so you can build a set out before it's
seen. Creating a set at all takes **owner**, **technician**, or **admin** — see
[Roles & Permissions](/help/permissions).

Two things that catch people out:

- The Owner's default has to stay public. Unset it as the default before you
  can make it private.
- If you own the machine and it has no default yet, your **first** set skips
  the draft stage — published and made the default straight away.

## Duplicating

A copy starts as a private draft owned by you, and its kind is re-derived from
who copied it — so your copy of someone else's **Owner** set becomes a
**Community** set you can actually edit. It carries the Tournament tag over; it
never inherits the default.

## Saving

There's no Save button. Every field is live and saves a moment after you stop
typing. If a save fails you get a banner with **Retry** and your edits stay
put.

## Also worth knowing

- **Before you change anything** and **How to change settings** are
  machine-wide — shared by every set, editable by anyone who can create one.
- Software settings, Post positions and Rubbers are one per set; they leave the
  **Add section** menu once you've used them. DIP banks, tables and notes
  repeat.
- Creating, editing and deleting a set record a **settings** entry on the
  machine's Timeline; publishing, tagging and changing the default don't. That
  filter is off by default.
