## Choosing a set

The set badged **★ Owner's default** is the configuration the machine's owner
considers canonical. Each machine has at most one, and it always sorts first.
**🏆 Tournament** marks a set as competition-ready. A set can carry both badges.

## Who can edit a set

Two independent properties decide this: a set's **kind** — Owner or Community,
fixed when it is created — and whether it is still a **private draft**. A draft
is limited to its creator and admins regardless of kind.

Drafts are hidden from everyone but their creator and admins, so a set can be
built out before it is published. Creating a set at all requires the **owner**,
**technician**, or **admin** role — see
[Roles & Permissions](/help/permissions).

Two exceptions are worth knowing:

- The Owner's default must stay public. Remove the default designation before
  making the set private.
- If you own the machine and it has no default yet, your **first** set skips
  the draft stage: it is published and made the default immediately.

## Duplicating a set

A duplicate starts as a private draft owned by you, and its kind is re-derived
from who copied it — so a copy of someone else's **Owner** set becomes a
**Community** set you can edit. The duplicate carries the Tournament tag over.
It never inherits the Owner's default designation.

## Saving

Settings save automatically. Every field is live and commits a moment after you
stop typing, so there is no Save button.

## Additional notes

- **Before you change anything** and **How to change settings** are
  machine-wide: shared by every set, and editable by anyone who can create one.
- Software settings, Post positions, and Rubbers are limited to one per set,
  and leave the **Add section** menu once used. DIP banks, tables, and notes
  can repeat.
- Creating, editing, and deleting a set record a **settings** entry on the
  machine's Timeline; publishing, tagging, and changing the default do not.
  That Timeline filter is off by default.
