## Choosing a set

Each machine can have one **★ Preferred House** set — how it runs day to day —
and one **Preferred Tournament** set for competition. Both sort first. One set
can be both.

Sets also carry **tags**. **House** and **Tournament** are built in: only a set
tagged House can be the preferred House set, and only a set tagged Tournament
can be the preferred Tournament set. A set can carry both tags.

Every new set starts as a personal set tagged House. Its author can make it a
community set from the ⋮ menu; that can't be undone. Creating a set requires
the **owner**, **technician**, or **admin** role — see
[Roles & Permissions](/help/permissions).

Everyone can see every set. Other people's personal sets are hidden until you
turn on **Others' personal** above the list, unless one is a preferred set.

## Tags and preferred sets

Technicians, admins, and the machine's owner can tag any set on the machine and
choose its preferred sets, even sets they can't edit. Choosing a new preferred
set replaces the old one.

- A preferred set is always a community set: making someone's personal set
  preferred turns it into a community set.
- A preferred set keeps its tag. Unset it before removing the tag.
- If a machine has no preferred House set, the next set created on it becomes
  the preferred House set.

## Duplicating a set

A duplicate is a personal set of yours with the same tags. It is never
preferred.

## Saving

Settings save automatically. Every field is live and commits a moment after you
stop typing, so there is no Save button.

## Additional notes

- **Before you change anything** and **How to change settings** are
  machine-wide: shared by every set, and editable by anyone who can create one.
- Software settings, Post positions, and Rubbers are limited to one per set,
  and leave the **Add section** menu once used. DIP banks, tables, and notes
  can repeat.
- The machine's Timeline shows sets being created and deleted and preferred
  sets changing. Edits, tags, and sets made community are recorded under
  **Settings edits**, a Timeline filter that is off by default.
