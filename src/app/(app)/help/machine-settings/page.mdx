## Before You Change Anything

The tab opens with **Before you change anything** — the owner's own request for
how people should handle this machine's settings: who to ask, how to make
changes, anything to avoid. It's optional, but even one sentence protects a
setup someone's dialed in.

## How to Change Settings

Below that, **How to change settings** holds machine-level instructions for
reaching this machine's adjustments: coin-door button meanings (back / value− /
value+ / enter), where the DIP switches are, the launch-button sequence on a P3,
and so on. It's shared by every settings set on the machine, and editable by
anyone who can create settings sets (see "Who Can Edit" below).

## Settings Sets

The **Settings** tab holds one or more **settings sets** — each a named,
standalone configuration (e.g. _Tournament_, _Home_, _Factory defaults_). Most
people are here for one thing: the machine's normal setup. Look for the set
with the **★ Owner's default** badge — it always sorts to the top — or filter
to **🏆 Tournament** if you want the competition config instead.

### Owner sets and Community sets

Every set belongs to one of two kinds, which decides who can edit it:

- **Owner set** — made by the machine's owner. Protected: only the owner and
  admins can edit it, even technicians can't.
- **Community set** — made by a technician or admin. Co-edited by any
  technician, plus the machine owner and admins.

### Private drafts and publishing

A new set starts as a **private draft**, visible only to the person who
created it (and admins) — so you can build it out before anyone else sees it.
**Publish** it from the set's ⋮ menu to make it visible to everyone; **Make
private** reverses that. The Owner's default is the one exception — it must
stay public, so unset it as the default before you can make it private again.

One shortcut: if you're the machine's owner and the machine has no Owner's
default yet, your first set skips the draft stage — it's published and made
the Owner's default straight away, since that's almost always what a first set
is for. Every set after that starts as a private draft like any other.

### The Owner's default

Each machine has at most one **★ Owner's default** — the setup the owner
considers canonical. It's always an owner set and always public. The owner (or
an admin) sets it from a set's ⋮ menu with **Set as owner's default**, which
replaces whichever set held the title before.

### Tournament

**🏆 Tournament** is an independent tag any set can carry — owner or
community — for a competition-ready configuration. A set can be both the
Owner's default and Tournament at once. Whoever can edit a set can tag or
untag it from the ⋮ menu.

### Filtering the list

Above the sets, a filter row narrows what's shown: **All / Mine / Owner's /
Community** (pick one), plus an independent **Tournament** toggle layered on
top — e.g. Community + Tournament shows only tournament-tagged community sets.
Click **All** to clear every filter and see everything again.

Two of those only appear when they'd tell you something: **Mine** shows up once
you've made a set of your own, and **Owner's** is hidden if you _are_ the
machine's owner — your sets are the owner's sets, so **Mine** already covers it.

### Duplicate

**Duplicate** (⋮ menu) copies a set as "_name_ (copy)". The copy always starts
as a fresh **private draft** owned by you, and its kind is re-derived from who
made it — so your copy of someone else's owner set becomes a **Community**
set you can edit, not a protected owner set you'd be locked out of. It never
inherits Owner's-default status, but it does carry over the Tournament tag if
the original had one.

### Delete

**Delete** (⋮ menu) removes the set and everything in it. Confirmation
required; it can't be undone.

## Sections

A set's body is an ordered list of **sections** added from **Add section**. Drag a
section by its grip to reorder; the ⋮ on each section deletes it.

- **Software settings** — the game's adjustments menu. Rows are **ID / Setting /
  Value** (e.g. `A.1 01` / `Balls Per Game` / `5`). Has a **baseline** picker for
  the overall starting point (Factory, Competition, …). One per set. _(How to
  reach the menu is recorded once, machine-wide, in **How to change settings** at
  the top of the tab.)_
- **DIP switch bank** — physical switches on EMs and early solid-state games. Each
  row is a switch number, an **ON/OFF** toggle, and a setting description. Repeats
  — add one bank per physical bank. Rename the bank inline.
- **Other table** — a free **ID / Setting / Value** table under a heading you set,
  for anything else (Jones plugs, transformer taps, board jumpers, rotary
  selectors). Repeats.
- **Post positions** / **Rubbers** — preset note sections with fixed headings, for
  the two most common physical-setup notes. One each per set.
- **Other / Notes** — a free note section with a heading you set. Repeats.

Note sections (Post positions, Rubbers, Other / Notes) take rich text — headings,
lists, bold, links.

## Editing a Set

Whoever can edit a set (see "Who Can Edit" below) just edits it directly —
every field is live, and your changes save automatically a moment after you
stop typing or move on. There's no separate Edit/Done step.

- **Desktop** — click into any value to change it. **Add row** appends a row;
  **Add section** adds a section; the trash icon on a row or section removes it.
  Drag sections to reorder.
- **Mobile** — tap a row to edit it in a sheet; toggles and inline edits live
  there.
- Deleting a section or row, and reordering sections, save right away.

If a save ever fails, a banner appears at the top of the page — your edits stay
put, and **Retry** re-sends them. Leaving the tab flushes any unsaved edits in
the background automatically.

## Who Can Edit

Creating a set — and editing the machine-wide **Before you change anything**
and **How to change settings** guidance — needs the machine's **owner**, any
**technician**, or any **admin**; see [Roles & Permissions](/help/permissions).
Once a set exists, who can edit that particular set depends on its kind and
visibility:

- **Owner set** — the machine owner and admins only.
- **Community set** — any technician, the machine owner, and admins.
- **Private draft** — only its creator and admins, regardless of kind (a
  technician's own community draft isn't open to other technicians until it's
  published).

Viewing a public set, or the Owner's default, is open to everyone. Without edit
rights on a set, its fields are read-only and its ⋮ menu doesn't appear.

## Timeline

Creating, editing, or deleting a set records a **settings**-tagged entry on the
machine's Timeline tab. Publishing, setting the Owner's default, and tagging
Tournament don't add timeline entries. The settings tag is **off by default** —
turn on the **settings** filter on the Timeline to see configuration history.
