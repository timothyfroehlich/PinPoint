The word “issue” is taken. It is PinPoint’s core noun for a machine fault — this same machine page has an Issues tab, an issue list, issue severities, “Report an issue”. A warning chip on that page reading Config issue is a second, unrelated meaning of the word a few hundred pixels from the first. Someone scanning the page for what is wrong with the game finds a thing labelled “issue” that is not one.

For scale, this is the neighbourhood the word already lives in on the same machine:

Issues · 2 open
#14 · Left orbit switch intermittent  major
#11 · Backglass lamp flickering  minor
If you want the “something is set up wrong” framing rather than the “here is a chore” framing, Setup issue and Needs fixing both carry it without the collision — but Needs cleanup still says the true thing most plainly: nothing is misconfigured, there is simply a leftover entry on a public map that someone should take down.

Also: “Config” is developer vocabulary. This chip is shown to every member, and APC members are pinball people, not sysadmins — “config” abbreviates a word that was already jargon.

Your call — it is copy, and copy is yours. Say the word and “Config issue” goes in.
