Rejected: a bare icon with meaning only in a tooltip fails CORE-A11Y-005 (title is not a tooltip) and is invisible on touch.

What each one actually says

TextReads asAgainst it
Needs cleanupA chore someone should do. Names the task, not a fault.“Cleanup” is mildly ops-flavoured.
Old listingNames the thing rather than the task — closest to the Manage-tab row, which says “Previous listing”.Doesn’t say anything is expected of you.
ResolveA verb; obviously clickable.Resolve what? Carries no information until you click.
Needs attentionNeutral, standard admin vocabulary.Vaguest of the set, and the longest that still nearly fits.
Configuration issueSomething is set up wrong.Wraps at 320 px, and “issue” collides with PinPoint’s own noun for a machine fault.

My pick: “Needs cleanup.” It fits, it names a task rather than a fault, and it doesn’t reuse “issue”, which already means a broken machine everywhere else in this app.

One consequence of dropping the label. With no “Pinball Map” key, the unlisted row has to carry the location link itself — hence Not listed on Pinball Map ↗ as a link. That is the attribution anchor for the whole card, so it can’t be plain text.
