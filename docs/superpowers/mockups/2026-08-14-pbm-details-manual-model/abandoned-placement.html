Where does the abandoned-listing notice and its removal control live?

PP-l81u shipped the read-only notice on the Info tab. PP-o355.32 will add a button that actually deletes the entry from pinballmap.com. The question is which tab gets which. Each option below shows both tabs so you can see what each reader ends up with.

A

Both tabs, different jobs

Info tab reports. Manage tab acts. Anyone visiting the machine learns something is unresolved; only someone with edit rights and working credentials gets the button.
